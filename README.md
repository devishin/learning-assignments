# learning-assignments

## Что это

Учебный мини-проект для отработки базового workflow Git: локальный репозиторий, коммиты, отправка на GitHub и оформление README.

## Как запустить/проверить

1. Склонируйте репозиторий:

```bash
git clone https://github.com/devishin/learning-assignments.git
cd learning-assignments
```

2. Запустите скрипт (нужен Python 3):

```bash
python main.py
```

Ожидаемый вывод:

```text
Привет!
Запуск: python main.py
```

3. Историю коммитов можно посмотреть:

- на GitHub: вкладка **Commits**;
- локально:

```bash
git log --oneline
```

## Что я сделал(а)

1. Создал папку проекта и файл `main.py`.
2. Инициализировал репозиторий: `git init`.
3. **Первый коммит** — добавил `main.py` с выводом «Привет!».
4. **Второй коммит** — добавил функцию `main` и подсказку запуска в `main.py`.
5. **Третий коммит** — добавил этот `README.md`.
6. Привязал удалённый репозиторий на GitHub (`origin`) и выполнил `git push`.

## Что было сложным / что понял(а)

- Коммиты лучше делать небольшими: один коммит — одна понятная задача.
- Сообщения коммитов должны совпадать с тем, что написано в README — так проще проверять работу.
- Перед `git push` нужно создать репозиторий на GitHub и связать его: `git remote add origin ...`.
