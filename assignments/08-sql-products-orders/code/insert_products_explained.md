# Как сгенерированы товары (seed.py)

## Зачем скрипт

В задании нужно **≥100 товаров**. Вручную в DBeaver долго; **`code/seed.py`** создаёт **120** позиций в **8 категориях** с разбросом цен и **40** заказов (5 из них с `is_test = 1` для безопасного `DELETE`).

## Запуск

Из корня репозитория (после `git clone`):

```powershell
cd assignments/08-sql-products-orders
python code/seed.py
```

Появится `products_orders.db` в этой же папке.

## Логика

1. Читает `sql/schema.sql`.
2. Генерирует SKU вида `ELE-0001`, `HOM-0002`, …
3. Добавляет 3 товара с префиксом **ABC** в имени — для демо `UPPER(name) LIKE 'ABC%'`.
4. Заказы привязаны к случайным `product_id`.

## Повторная генерация

Скрипт **удаляет** старый `products_orders.db` и создаёт заново. Запросы из `sql/queries.sql` (ручные INSERT/UPDATE/DELETE) выполняйте **после** seed в DBeaver или на копии базы.
