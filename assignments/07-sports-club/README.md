# Домашнее задание: база данных «Спортивный клуб»

SQLite-база для учёта участников, тренеров, занятий, записей, посещений и оплат.

## Таблицы (8)

| Таблица | Назначение |
|---------|------------|
| `members` | Участники клуба |
| `trainers` | Тренеры |
| `membership_types` | Виды абонементов (цена, срок) |
| `memberships` | Выданные абонементы участникам |
| `classes` | Групповые занятия в расписании |
| `class_enrollments` | Запись участника на занятие (M:N member ↔ class) |
| `visits` | Фактические посещения |
| `payments` | Платежи (часто привязаны к абонементу) |

Связи: у тренера много занятий; у участника много абонементов, записей, посещений и платежей.

## Ограничения

- **NOT NULL** — обязательные поля (имена, email, даты, суммы и т.д.).
- **UNIQUE** — `members.email`, `trainers.email`, `membership_types.name`.
- **CHECK** — `capacity > 0`; `price > 0`; `amount > 0`; `end_date > start_date`.
- **Триггеры** — возраст участника ≥ 14 лет (`members_age_check_*`).
- **FOREIGN KEY** — все связи между таблицами.
- **Индексы** — `memberships(member_id)`, `class_enrollments(class_id)`, `visits(member_id)`, `visits(visited_at)`, `classes(trainer_id)`, `classes(starts_at)`.

## Что показывают запросы (`checks.sql`)

1. Активные абонементы на сегодня  
2. Число записей на занятия по датам  
3. Тренеры и их классы  
4. Участники без визитов > 30 дней (при активном абонементе)  
5. Топ-3 занятий по посещениям  
6. Выручка по типам абонементов  
7. Конфликты расписания (пересечение занятий у одного участника)  
8. Занятия со свободными местами  
9. Нагрузка тренеров (число классов)  
10. Запись на занятие при истёкшем абонементе  

## Как запустить (4 шага)

### 1. Откройте проект в DBeaver

**База → Новое соединение → SQLite →** укажите путь к `sports.db`  
или создайте пустой файл и выполните `schema.sql`.

### 2. Схема

```text
File → Open SQL Script → schema.sql → Execute
```

### 3. Данные

```text
seed.sql → Execute
```

После клонирования репозитория перейдите в папку задания и соберите базу:

```powershell
cd assignments/07-sports-club
python build_db.py
```

(из корня клона `learning-assignments`, или укажите полный путь к этой папке у себя на диске.)

### 4. Проверочные запросы

```text
checks.sql → выполнить по блокам или целиком
```

```powershell
python export_screenshots.py
```

Пересобрать ER-картинку:

```powershell
pip install pillow
python render_erd.py
```
