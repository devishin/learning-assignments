# Настройка VK для бота

1. Сообщество → **Управление** → **Работа с API** → ключ с правом **Сообщения сообщества**.
2. **Long Poll API** → включить событие **Входящее сообщение** (`message_new`).
3. В **Настройки для бота** включить **Возможности ботов** (кнопки клавиатуры).
4. Скопировать ключ в `.env` как `VK_BOT_TOKEN`; при необходимости указать `VK_GROUP_ID`.

Запуск: `python bot.py` (Long Poll, vkbottle). В диалоге с сообществом: **начать** → меню кнопок.
